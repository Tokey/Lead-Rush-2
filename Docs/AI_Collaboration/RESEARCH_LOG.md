# Research log: AI agents coordinating on one codebase

Raw material for a possible paper on how several AI coding agents can build one game together. The story is told in
[README.md](README.md); this file keeps the data. Times are local (America/New_York). Sources: the board and its
[archive](archive/), the Claude Code and Antigravity session logs ([prompts](PROMPTS.md)), and git history.

## Setup

| Variable | Value |
|---|---|
| Project | LeadRush 2, Unity 6000.5.0f1 HDRP first-person shooter; all content generated by editor builders |
| Agents | Claude Code (`claude-opus-5-5`); Antigravity agent "Gemini" (`claude-opus-5-5-high`, `gemini-4-hydrogen`, "argon" = `gemini-pro-orchestrator-g1-pro` + `gemini-flash-worker-agy`, one `gemini-3.8-flash-low` call); GitHub Copilot agent (model not recorded yet) |
| Channel between agents | One Markdown file in the repo (`AGENT_COORDINATION.md`); no direct messages until 23:46 on 11-17 (see `[PROMPT]`) |
| Exclusive resource | The Unity editor (one process per project) |
| Human role | Goals, playtests, decisions; prompts any agent; often away |
| Constraint that shaped everything | Per-agent usage limits (5-hour and weekly windows) |

## Metrics

The first three are computed by [`analysis/analyze.py`](analysis/analyze.py) from [`data/`](data/); charts in [`figures/`](figures/).


- **Defects per task, per agent and per model:** tracker rows with kind `bug`, grouped by the `Caused by` task and its model. The
  first reconstruction is in [README.md](README.md#quality-bugs-traced-back-to-the-work-that-caused-them).
- **Review yield:** `REOPENED` count / reviews done, and `[REVIEW-CATCH]` events per agent.
- **Time to verify:** `READY FOR REVIEW` to `VERIFIED`, from the `Updated` column and the log.
- **Coordination overhead:** board size and edits per hour; share of each agent's turns spent on the board.
- **Handoff survival:** work items still on track one hour after a `[HANDOFF]`.
- **Incident rates:** `[LOCK]`, `[MISATTRIB]`, `[OWNERSHIP]`, `[CLOCK]` events per hour of three-agent work.
- **Throughput by model:** rows closed per active hour for each agent and model.

## Open questions

1. Does pairing an implementer with a separate reviewer (forced by different usage limits) raise quality enough to pay for the
   extra coordination? The tracker's `REOPENED` and `Caused by` columns are meant to answer this.
2. How should agents establish identity when tools share models? Naming by tool worked twice, but only after a failure each time.
3. What is the cheapest reliable liveness signal between agents that cannot message each other (heartbeat rows, lock lines, process
   checks)?
4. How much of a handoff survives a hard usage-limit stop, and what must a handoff contain to make it lossless?
5. When should agents fan out sub-agents? Three fan-outs died at a usage limit with no output; inline work never lost results.
6. Do QA checks written by the implementing agent measure the right thing? One passed while the bug was visible in its own
   screenshot.
