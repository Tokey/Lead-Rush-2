# P5 - Graphics presets

LR2 already persists quality level, VSync, frame limit, FPS display, motion blur,
film grain and ray tracing. The next step is to make preset names and behavior
predictable instead of exposing an implementation-dependent quality index.

## Preset contract

| Preset | Priority | Expected workload |
|---|---|---|
| Low | stable competitive frame time | lowest shadows/reflections, shorter effects, no DXR |
| Medium | balanced 1080p/1440p | moderate shadow/reflection/detail, no DXR by default |
| High | visual quality | higher HDRP settings and detailed effects |
| Ultra | screenshot/cinematic quality | maximum quality, DXR optional and clearly labeled |

Players should understand that Ultra is not a promise of higher FPS. DXR is a
separate checkbox when supported and can raise cost substantially.

## Implementation rules

1. Map preset names to Unity Quality Level indices once in a shared helper.
   Settings UI should show `LOW`, `MEDIUM`, `HIGH`, or `ULTRA`, not raw indices.
2. Preserve `LR2Settings.QualityLevel`, VSync, frame limit and RayTracing keys.
   Invalid quality indices should fall back to the closest existing level.
3. Apply `QualitySettings.SetQualityLevel(q, true)`, then apply the ray-tracing
   controller. Rebuilding the HDRP asset at runtime should be avoided.
4. Keep VSync and FPS limit as separate controls. A 144 Hz screen with VSync on
   needs no 60 FPS cap unless the player chooses it.
5. FPS display, film grain and motion blur are independent preferences. A preset
   must not silently reset accessibility or view preferences.
6. On unsupported ray-tracing hardware, disable and explain the DXR toggle;
   never save a ray-tracing value that silently has no effect.

## Acceptance

- Low/Medium/High/Ultra names appear consistently in the settings panel.
- Switching presets changes measurable GPU/quality settings and persists.
- Switching to unsupported DXR hardware produces no runtime error.
- A 30-second benchmark at 1080p is attached to P3 for each stable preset.
- Screenshot strings, tooltips and reset behavior match `LR2Settings`.
