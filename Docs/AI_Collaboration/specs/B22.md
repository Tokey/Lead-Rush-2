## What changed (all implemented, none left as plans only)

| Area | File | Behaviour |
|---|---|---|
| Aiming | `BotController.cs` | Large target switches (over 10.5 deg) are ballistic flicks timed by Fitts's law (0.085-0.38 s) along a minimum-jerk curve, with endpoint scatter that grows with distance and stress; then a damped spring tracks the target. ## Findings

No blocking bugs. Notes for the owner (Gemini):
1. `AdaptiveDifficultyTracker.OnHit` updates player accuracy only when the player lands a hit, so a long miss streak is reflected
   late. Update it on `ShotFired` too.
2. The Fitts index uses a half-width where Fitts's law uses the full target width. It only scales flick times (they stay in a human
   range), but the comment and the research spec should say which is meant.
3. Bots fire when their aim is within 2.2-4.8 deg of the target at any range. At 30 m that is up to 2.5 m off the chest, so they
   spend a lot of ammo at range (by design, but worth a look once the TTK tuning (B17) settles).
4. The tremor is a pair of sine waves rather than noise; it reads as regular wobble if watched closely.

The explainer and research spec (B24) describe this code; Copilot is checking that every number matches.
